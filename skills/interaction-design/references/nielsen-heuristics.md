# Nielsen: usability inspection

Source: Jakob Nielsen, [10 usability heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/). Paraphrased prompts:

1. **Status:** can the user tell what is happening?
2. **Real-world match:** do labels reflect the user's language and task?
3. **Control:** can the user leave or reverse a mistaken action?
4. **Consistency:** do equivalent actions behave alike and follow useful conventions?
5. **Prevention:** can the interface stop a consequential mistake before submission?
6. **Recognition:** is needed information visible rather than dependent on memory?
7. **Efficiency:** can frequent users work faster without obstructing newcomers?
8. **Focus:** does unnecessary content compete with the task?
9. **Recovery:** does an error explain the problem and a useful next step?
10. **Help:** is relevant guidance available when needed?

Do not report ten findings just because there are ten prompts. Group symptoms sharing one cause. A sparse interface is not inherently better; task-relevant detail can prevent mistakes. For conducting the inspection, see [NN/G's evaluation method](https://www.nngroup.com/articles/how-to-conduct-a-heuristic-evaluation/).
