# Visual foundations and application

These are toolkit review prompts. Design systems below illustrate coherent choices within their own products; their brand values and numeric scales are not universal requirements.

## Type and density

Use a small set of purpose-named type roles. Compare a title, a long paragraph, a label and numerical data in the actual chosen font. Example: a financial table may need stable numeral alignment while an article needs comfortable continuous reading. Assess wrapping before shrinking text. Avoid declaring a fixed number of fonts or a mathematical scale mandatory.

Sources: [Carbon typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/type-sets) and [Material applying type](https://m3.material.io/styles/typography/applying-type). These are first-party system examples.

## Spacing and grouping

Use relative distance to express relationships. Example: keep a field's label and hint closer to it than the next field. Reuse a spacing token if it expresses that relationship; do not treat token adherence as proof of good composition. Alignment can be optical as well as geometric.

Source for the grouping mechanism: [proximity](https://www.nngroup.com/articles/gestalt-proximity/), a secondary explanation of Gestalt perception.

## Colour roles

Document what a colour means before adding another swatch. Example: distinguish a selected item from a destructive action through role-specific treatment. Check themes and state combinations, and provide cues beyond hue when colour communicates meaning. Avoid assuming that cultural associations are shared by every audience.

Example system: [GOV.UK colour guidance](https://design-system.service.gov.uk/styles/colour/). Use its role-based approach as a reference, not its palette as a replacement for the product brand.

## Composition and polish

Toolkit judgement: compare the same component across screens before changing the system. A one-off misaligned icon may need a local correction; repeated competing heading styles may need a type-role decision. Prefer a change with a stated task or brand benefit over stylistic novelty. Validate the result at its intended size with actual content; a zoomed mock-up can conceal density problems.
